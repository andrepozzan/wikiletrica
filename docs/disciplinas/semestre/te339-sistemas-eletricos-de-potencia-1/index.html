TE339 - Sistemas Elétricos de Potência I

Semestre: 6º Semestre
Carga horária: 60 h
Departamento: Engenharia Elétrica - UFPR

📚 Visão Geral da Disciplina​

Sistemas Elétricos de Potência I estuda a estrutura do Sistema Interligado Nacional (SIN), o sistema de unidades Por Unidade (pupupu), o cálculo dos parâmetros elétricos das Linhas de Transmissão aéreas (resistência com efeito pelicular, indutância com raio médio geométrico RMG e capacitância com método das imagens), e os modelos de linhas curtas, médias (circuito π\piπ) e longas com reflexão hiperbólica.

📑 Principais Tópicos Teóricos​

1. Sistema Por Unidade (pupupu)​

Permite normalizar grandezas de diferentes níveis de tensão transformados no mesmo sistema elétrico:

Sbase=constante em todo o sistema (ex: 100 MVA)S_{\text{base}} = \text{constante em todo o sistema (ex: 100 MVA)}Sbase​=constante em todo o sistema (ex: 100 MVA) Zbase=Vbase2Sbase,Ibase=Sbase3VbaseZ_{\text{base}} = \frac{V_{\text{base}}^2}{S_{\text{base}}}, \quad I_{\text{base}} = \frac{S_{\text{base}}}{\sqrt{3} V_{\text{base}}}Zbase​=Sbase​Vbase2​​,Ibase​=3​Vbase​Sbase​​

Mudança de base de impedância:
